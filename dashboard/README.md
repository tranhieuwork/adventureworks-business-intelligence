# AdventureWorks Business Intelligence Dashboard

## Overview

This directory contains the Power BI dashboard developed for the AdventureWorks Business Intelligence project.

The dashboard focuses on three key business areas:

- **Procurement Performance:** Analyze purchasing activities and related performance indicators.
- **Vendor Management:** Monitor and evaluate vendor performance.
- **Manufacturing Production:** Analyze production activities and operational performance.

## Tools

- Microsoft Power BI
- Data Visualization
- Business Intelligence

## How to View

1. Download `AdventureWorks_Business_Intelligence_Dashboard.pbix` from this directory.
2. Open the file using Microsoft Power BI Desktop.
3. If prompted, configure the required data sources.

**Note:** Dashboard functionality may depend on the original data sources and connections configured in the project.
