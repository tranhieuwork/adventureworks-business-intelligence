# Dashboard Screenshots

## Overview

This directory contains screenshots of the Power BI dashboards developed for the AdventureWorks Business Intelligence project.

The screenshots provide a visual overview of the dashboards and their key business insights without requiring users to open Power BI Desktop.

## Dashboard Previews

| Screenshot | Description |
|---|---|
| `overview_dashboard.png` | Overview of the Business Intelligence dashboard. |
| `procurement_dashboard.png` | Visualization of procurement performance and purchasing activities. |
| `vendor_management_dashboard.png` | Visualization of vendor performance and related metrics. |
| `manufacturing_dashboard.png` | Visualization of manufacturing and production performance. |

## How to View

Click on any screenshot in this directory to view the dashboard visualization.

For the interactive dashboard, see the [`dashboard/`](../dashboard/) directory.
