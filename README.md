# AdventureWorks Business Intelligence Project

A Business Intelligence project using the AdventureWorks dataset to analyze procurement performance, vendor management, and manufacturing operations through data warehousing, OLAP, and interactive Power BI dashboards.

## Project Overview

This project was developed as part of a group academic project at the University of Economics and Law (UEL), Vietnam National University Ho Chi Minh City, in July 2025.

The objective was to develop a Business Intelligence solution that transforms business data into meaningful insights to support operational monitoring and performance analysis.

The project focuses on three key business areas:

- **Procurement Performance:** Analyze purchasing activities, purchase orders, and procurement-related performance indicators.
- **Vendor Management:** Monitor vendor performance and evaluate supplier-related metrics.
- **Manufacturing Production:** Analyze manufacturing activities and production performance.

## Technologies & Tools

- **Microsoft Power BI** — Interactive dashboards and data visualization
- **SQL Server** — Data storage and database management
- **SQL Server Integration Services (SSIS)** — ETL and data integration
- **SQL Server Analysis Services (SSAS)** — OLAP and analytical data modeling
- **Data Warehouse & Data Mart** — Analytical data organization
- **Business Intelligence** — KPI monitoring and business performance analysis

## Project Workflow

The project follows a Business Intelligence workflow:

1. **Business Analysis:** Identify business requirements and performance indicators.
2. **Data Integration:** Extract, transform, and load data through the ETL process.
3. **Data Warehousing:** Organize data for analytical reporting.
4. **OLAP Development:** Support multidimensional analysis of business data.
5. **Dashboard Development:** Build interactive Power BI dashboards to visualize business performance.

## Key Performance Indicators

The project report presents procurement-related indicators, including:

- **Total Purchase Amount:** Approximately $20.06 million
- **Return Rate:** 3.40%
- **Receive Rate:** 99.12%

These figures are presented in the project's procurement dashboard. Their definitions and calculation methods should be interpreted in the context of the project report.
